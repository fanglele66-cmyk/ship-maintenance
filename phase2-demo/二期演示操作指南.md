# 船舶设备检修助手｜展会演示操作指南

建议 Pad 横屏使用。整船首页右侧直接展示一条船舶运行概况，包含航行工况、重点设备监测回顾及建议处理事项。点击消息内「哪些需要人工跟进」「提前维保依据」即可看到对应追问与回复，无需输入；「查看主机设备态势」进入设备层。逐日观察与现场确认保留在对应设备和事项内，不在整船层模拟处理完成。开始互动演示前可在待办中心点击「重置模拟数据」。所有数据均为演示样本。

## 核心位置

- **待办中心**：需要人工确认、检查、排查与维修保养的事项。状态只有「未处理 / 已处理」；措施及现场验收提交后即为已处理。
- **设备态势 → 关注事项**：AI 跟踪、待人工确认、观察已结束。未形成待办的关注，以及处理后的效果观察，都在这里查看。
- **设备态势 → 维保计划**：提前维保建议与常规计划。点击卡片进入计划概览、分析依据、跟踪记录三个页签；计划不重复生成任务。
- **案例材料**：处理完成后自动汇集原始证据、人员反馈、原因分析与实际措施，标注来源事件；观测结果继续关联补充。船端无需填写或导出案例。当前展示岸端待审阅状态，岸端建议、编辑和沉淀界面后续建设。

候选原因仍是事件概览的第三个页签。检查确认异动是否真实；异常确立后，排查寻找导致现象的原因。

## 场景一｜预测性维保

详情先展示计划概览中的结论、建议及“当前安排与关联”；切到分析依据逐章节查看变化原因，切到跟踪记录回看首次发现、趋势更新、计划窗口、人员决定与现场反馈。右侧助手同步显示同一条证据接续链，无需输入即可阅读。

1. 「态势」→「1号主机」→「维保计划」→「提前维保建议」，点「主机1#缸连杆轴承建议提前维保」。阅读振动趋势、周期节点、靠港窗口及检查建议。
2. 右侧点「确认建立检查待办」，再点「查看关联待办」。
3. 「建议速览」查看结论和依据；进入检查准备，点「已了解，开始检查」。两项依次选「发现轻微偏磨」「间隙接近上限，备件可用」，提交。
4. 保养换件步骤选择已完成；验收确认勾选两项，复测记录可填「已更换轴瓦并复装，间隙复测合格，润滑正常；试运转振动2.2 mm/s、温度64°C」，提交。
5. 待办显示已处理。点「查看设备态势中的效果观察」，上方趋势自动补入第1日、第2日数据；右侧每日回顾回应原先振动缓升的研判。48小时持续稳定后自动结束观察。
6. 「观察时间线」回看每日记录；返回关注列表，在「观察已结束」找到同一事项。

## 场景二｜持续监测，无明确故障

1. 「态势」→「1号主机」→「关注事项」→「AI 跟踪」，点「海水冷却泵出口压力轻微波动」。
2. 右侧自动推送第2日与第3日比较，间隔约5秒。压力波动未扩大，流量与水温没有同步恶化。
3. 专项观察自动结束，在「观察已结束」回看证据与收束原因；全程未生成待办。

## 场景三｜新证据引导人工确认，再排查原因

1. 「态势」→「1号主机」→「关注事项」→「待人工确认」，点「主机3#缸排温偏离渐高」。详情和右侧会话已有第1日关注、第2日新证据：同工况排温差8→10°C，排温432°C。
2. 点右侧「确认建立检查待办」和「查看关联待办」。检查阶段选「现场与系统一致」「异响可复现」并提交。此步只确认异动真实性及响应需要。
3. 事件概览接续，第三个页签查看「候选原因」，进入排查。喷油器选「发现异常」，排气阀选「未见异常」，提交。
4. 维修阶段记录喷孔积炭清洁、校验与复装；完成验收并记录「喷雾形态正常、无泄漏，同工况排温差3°C，异响未再复现」，提交。
5. 待办已处理。进入态势效果观察：排温差和3#缸排温按日记录，右侧说明与原偏差、异响证据的对应关系。24小时稳定后结束观察。

## 场景四｜正常故障检测与处理后观察

1. 「待办中心」打开优先卡「主机冷却水温异常偏高」。查看概览及数据观测中的温度、流量多趋势对比；候选原因位于概览第三个页签。
2. 排查选择滤器「发现异常」、温控阀「未见异常」，提交。
3. 维修完成滤器清洗与复装，在验收确认勾选两项并记录「流量86.5 m³/h，出口温度79.1°C，复装无泄漏」，提交。
4. 待办已处理，点击「查看设备态势中的效果观察」。趋势与右侧会话自动更新第1日，24小时稳定后本轮观察结束；不是在事件中手动归档。
5. 在「观察时间线」查看逐日证据。可选演示：右侧输入「本日数据缺失，工况不同」，会建议延长；点「按建议延长跟踪24小时」后补入新一天点位及记录。输入「出口温度再次升高，流量又下降」，会建议人工复查；确认重新排查后回到待办，保留上一轮观测证据。

## 观测页与设备履历

「今日观测」展示趋势、当前读数、当日结论与建议；「观察时间线」展示每日记录与历次复查轮次。日更新自动模拟，页面没有「查看下一轮监测 / 记录下一日观测」按钮。仅需人员决定的复查或延长建议提供确认入口。

设备履历通过下拉框按实际维护、检查与处置事件、历史关注、维保建议、每日健康回顾分类。事件记录直接打开关联待办，历史关注和维保建议进入原事项材料；实际维护记录与每日回顾打开报告。实际维护记录在人员确认作业后出现，报告内可回看来源待办或关联效果观察。单传感器卡片展示采集值与趋势入口，不添加未经确认的参考范围与状态标识。
