# 船舶设备检修助手二期源码包

Vue + Vite 本地交互原型，包含四条演示叙事线。模拟数据无需账号、API 密钥或后端。

## 本地运行

1. 安装 Node.js 20 LTS 或更新 LTS。
2. 切换到本仓库的 phase2-demo 目录（含有二期 package.json）。
3. 执行 npm install，再执行 npm run dev。
4. 浏览器打开终端显示的地址，默认 http://localhost:5173/#/situation。首页展示船舶运行概况，右侧会话随当前查看内容呈现。

生产构建执行 npm run build，输出在 dist/；执行 npm run preview 可预览构建结果。若端口占用，Vite 会显示新地址。

src/ 是页面、组件与模拟数据；public/ 是静态资源；「二期演示操作指南.md」含四条故事的点击和对话步骤。无需发布平台凭据即可本地运行；发布配置与本地运行无关。源码包不包含 .git、node_modules 或 dist，同事可按 package-lock.json 安装依赖。

建议 Pad 横屏体验。首次打开「态势」会自动播放导览；末尾可点击按钮进入设备态势或待办中心。设备页的传感器列表和趋势整合在「传感器数据」页签中，沿用一期筛选、多趋势对比及时间范围控件。想按操作指南进行交互演示时，可在「待办中心」点击「重置模拟数据」。


人工措施及验收提交后，待办显示已处理；持续效果观察在「态势 → 1号主机 → 关注事项」中自动按日模拟。船端案例无需手动填写，材料按来源事件自动汇集，岸端审批为后续规划。
