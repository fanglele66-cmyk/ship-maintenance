# 四事件操作脚本

按“事件发现 → 现场确认原因 → 具体处理 → 验收 → 效果观察 → 人工闭环”的顺序操作。下面给出四条完整路径及可以逐项填写的记录。

| 事件 | 现场确认的原因 | 具体处理 | 验收重点 |
|---|---|---|---|
| 二缸报警与喷射控制核实 | 二缸 ICU 伺服油液压活塞卡滞 | 检查清洁后复验仍卡滞，按批准范围换装适配 ICU，恢复接口与密封 | 液压动作、喷射指令与反馈、接口密封、原报警复核 |
| 控制空气低压核实 | 控制空气减压阀阀芯密封垫老化破损 | 更换适配阀芯密封垫，复装并验证调压与压力保持 | 阀门密封、调压动作、现场压力与安全监测通道 |
| 一缸排温长期基线抬升跟踪 | 一缸喷油器喷嘴积碳导致雾化不良 | 清除喷嘴积碳，雾化、启喷与密封复验合格后装复 | 喷油器检验、接口密封、六缸同工况响应 |
| 四缸排温相对基线下移跟踪 | 四缸排气温度探头接线端子松动 | 恢复端子连接、核对极性与屏蔽，完成独立校验 | 端子连接、校验误差、通道对应、同工况读数 |

## 操作顺序与填写原则

1. **派发**：填写负责人、处理范围与反馈要求、要求完成时间。时限选择当天 18:00；若已过，选择次日 18:00。已派发任务直接进入核实，不重复派发。
2. **排查**：打开待办后，顶部查看负责人、要求完成时间与当前进度；在原因排查（或基线核实）的“数据观测”页签先核对测点与时间窗，再阅读准备项、逐项检查。选择检查结果，把具体原因填入对应检查项的备注。保留“现场确认：……”完整句子，维修方案据此收敛到具体部件和措施。
3. **作业**：左侧按步骤填写，右侧可一次填写整表。每项选择完成情况；备注为选填，需要说明措施时可复制下文。提交整表后，右侧才出现验收表单。
4. **验收**：右侧逐项填写验收记录，左侧表格同步显示；核对实际执行时间、实际措施、总体验收结果和验收结论，再提交。一个入口提交即可。
5. **文件**：点击聊天框左下角“＋”上传 TXT、Markdown、CSV 或 JSON，核对解析预览后写入当前表单，再手动提交。
6. **观察与闭环**：传感器数据自动更新，不重复手填。出现异常时提交复查依据；提前闭环时说明验收依据、尚未覆盖的观察范围和后续安排。
7. **异动维保**：完成核实后由轮机长形成建议并确认窗口。关联维保任务承接检查、维修与验收；事件概览中的“查看关联维保任务”打开“维保任务”页签，可查看负责人、工单及处理记录。

右侧助手先给出简短判断和建议动作，可展开“判断依据”核对支持材料。需要填写时使用建议动作进入当前表单，提交记录仍保留在会话中。异动事件的长期趋势在“研判分析”中查看，完整执行过程在“处置记录”中回查。
