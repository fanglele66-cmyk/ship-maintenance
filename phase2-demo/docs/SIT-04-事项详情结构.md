# SIT-04：事项详情页结构与内容

基线：船端公网V20，Sites源码7535986。用户暂定并授权执行页签“事项概览 / 研判分析 / 证据资料”。本轮范围仅事项处置行进入、尚未进入待办的详情，具体待办阶段卡不修改。

## 确认结构

- 事项概览：初判结论与建议先行；关键依据摘要可视呈现；推理摘要可选展开；中间有“查看研判分析”“查看证据资料”快链；最下方是下一步选择及标准指派表单。
- 研判分析：观察事实、推断关系、候选解释及尚未确认问题分层；可返回事项概览并恢复阅读位置。
- 证据资料：可核对的数据快照、已有观测节点、关联证据、配置/计划来源、人员补充及已有决定。不得用假时间点拼连续趋势，不捏造置信度或维保说明书来源。
- 趋势呈现规则（2026-10-13 用户确认方向）：已有观测节点达到2个及以上的（预警油压/滤器压差、异动排温与相对差、空压机加载时间、维保振动）以节点折线呈现，节点标签沿用现有观测口径，不补时间点；仅单点快照的（报警、舵机）明确标“暂无连续记录”，不造连续数据。
- 四类共用框架及组件，内容通过JSON配置。报警重在触发与关联信号；预警重在多指标联动；异动重在偏离及发展；维保重在原计划与提前依据。
- 派发入口只在首个页签下方。复用TaskAssignment/InquiryMessage，保留误报反馈，保留SIT-03派发后返回发起清单。

## 内容参照

现有issueCatalog作为数值及事项定义基线，不替换成旧事件数值。当前候选一期结构参照为仓库保留的ProductDrawer.vue（来源提交4620ea5）：初判结论与建议、数据概览、测点选择与趋势查看。用户已确认以这份为结构参照；只参考初判/建议及测点快照、选择查看趋势的方式，不搬用旧数值或置信度。
