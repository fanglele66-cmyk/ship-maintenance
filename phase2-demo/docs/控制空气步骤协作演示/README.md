# 控制空气双测点低压核实 · 步骤协作

事件：CBY-EVT-20260523-001（`real-warning-0523`）。本目录参照二缸目录，提供从任务开场到提交报告的完整操作路径和可直接发送的原话。

## 入口与流转

1. 轮机长打开控制空气事件的初始信息，核对四项排查建议，选择“派发排查”，执行人为李建国（大管轮），要求完成时间选择当前时间之后。切换为大管轮，从任务页进入第 1 轮排查。
2. 按[排查脚本](排查演示脚本.md)填写、核对并提交。
3. 轮机长审阅排查报告后，选择“派发维修”，核对一号减压阀已定位的密封垫问题，明确 WO-AIR-001 范围。二号供气路径保留，不扩大为全部阀组或空气供给部件更换。切换为大管轮进入维修任务。
4. 按[维修脚本](维修演示脚本.md)逐步记录。本路径包含未完成验证，提交后保留剩余事项，由轮机长安排等待条件或剩余任务，不直接宣布闭环。

## 操作约定

每个任务共用一段对话，切换左侧步骤后，助手围绕当前步骤答疑。船员可随时直接选结果、写备注并提交，也可以先在右侧咨询。

需要确认现场情况时，在该条助手回复内选一个符合现场的答案并确认。没有符合的选项时，选「其他」，填写自己的情况后发送。也可以继续直接问助手。后续答疑仍在正常对话中显示，船员可以核对并采用随答复整理的草稿。

回复先答疑，再显示本步备注草稿和补充确认。选「采用到本步骤」并点「确认」即可写入备注。需要改稿时，选「其他（补充或修改）」；只有草稿时选「继续修改」。在选项内填写内容并确认。

在左侧本步备注区点「拍照」或「上传照片」。也可在右侧当前步骤的对话中选图并发送。提交时，两处原图随所属步骤的结果、备注一起归档；同一步从两处提交同一原图，只保留一份，并标明两个来源。

报告有照片时，下载 ZIP，内含 Markdown 报告与照片文件；没有照片时，直接下载 Markdown（.md）。

已有派发任务是快照；进入前核对本目录列出的步骤标题与数量。旧任务或人工改过的方案若不一致，按其实际范围执行，不覆盖已有记录。轮机员提交前到任务页查看和填报，提交后事件页显示本轮只读记录。

## 步骤与人员选择

| 任务 | 步骤 | 选择的结果 |
| --- | --- | --- |
| 排查 | 1. 核对压力测点及时间对应 | 现场与系统一致 |
| 排查 | 2. 核对工况及临时恢复解释 | 工况可比，偏离仍存在 |
| 排查 | 3. 核查空气减压阀状态 | 发现异常 |
| 排查 | 4. 核查控制空气供给及工况 | 未见异常 |
| 维修 | 1. 作业准备与安全隔离 | 准备与隔离核对已完成 |

| 维修 | 3. 复装与分阶段试验 | 复装或试验仍有未完成项 |
