## 只读数据库核对方法

数据库：`D:/zstech/ship_sop/ship-data-collector/ship-data-collector/data/ship.db`。

连接用 Python 标准库 `sqlite3.connect('file:…/ship.db?mode=ro', uri=True)`，不执行写入语句。数据表 `sensor_readings` 的 `data` 为59项JSON数组；筛选 `ship_code='CHBY' AND device_code='DEVICE1'`。时间为来源文本，按原时刻使用，没有转换UTC。没有插值、前向填充或更改原值。

```sql
SELECT id, timestamp, data
FROM sensor_readings
WHERE ship_code = 'CHBY' AND device_code = 'DEVICE1'
  AND timestamp BETWEEN ? AND ?
ORDER BY timestamp;
```

映射由 `ship-data-collector/ship-data-collector/config.yaml:50-111` 的 `sensor_map` 段及 `ship-fault-diagnosis/ship-fault-diagnosis/references/sensor-mapping.md:7-74` 核对。只读取映射段，没有读取连接设置。数组下标为DC编号减1。

| 数据 | DC编号 | 下标 | 单位 |
|---|---|---|---|
| 主机转速 / 增压器转速 | DC0001 / DC0002 | 0 / 1 | RPM |
| 起动空气 / 控制空气 / 安全压力 | DC0005 / DC0006 / DC0007 | 4 / 5 / 6 | MPa |
| 1—6缸排温 | DC0008—DC0013 | 7—12 | °C |
| 二缸排温偏差原通道 | DC0015 | 14 | °C |
| 二缸活塞冷却油温 | DC0032 | 31 | °C |
| 二缸冷却淡水出口温度 | DC0047 | 46 | °C |

燃油指令是控制量，仅描述实际工况，不按映射表的典型满载范围认定越限。二缸活塞油温不是DC0039；后者是减振器油压。排温与排温偏差同源，不能计为两份独立的物理证据。
