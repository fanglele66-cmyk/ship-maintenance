# 船端：相对组长版 93aee39 的优化

仓库：fanglele66-cmyk/ship-maintenance；分支：phase2-demo-20261009。

比较基线为组长改良版 93aee39。关注档案、对话渲染组件和会话管理已在该基线中存在，不计入本轮新增。

## 本轮改动

1. 维保详情不再堆叠成长页，分为计划概览、分析依据、跟踪记录；概览先看当前结论、安排及可操作入口，依据分章节阅读，记录保留时间接续。
2. 提前建议与常规计划复用 MaintenanceDossier 和 SituationReport；静态页签、章节及入口配置进入 maintenance.json，业务状态仍由适配器计算。
3. 建立待办、查看关联待办、查看修后观察各有明确入口；读取 JSON 不会自动推进状态。提前建议不替代原周期计划，检查不等于换件，已处理不等于观察已结束。
4. 去掉维保页重复标题，保持关注档案与维保材料的阅读方式一致；新增规范化维护说明和状态检查。

## 体验路径

态势 → 1号主机 → 维保计划 → 提前维保建议或常规计划 → 查看三个页签。提前建议确认建立待办后，可进入关联待办推进检查与实际处理，再回到态势查看效果观察。

## 验证与边界

六个测试文件共11项检查通过，生产构建通过。此次同步的是可编辑源码；本次没有重新发布船端公网。组件及 JSON 规范化以维保详情为范围，不宣称全站完成配置化。
