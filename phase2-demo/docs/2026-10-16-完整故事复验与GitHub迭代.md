## 本次复验发现并修复

1. **派发返回位置**：原来只有从全船事项进入才回全船，从设备详情进入派发仍留在设备层。现统一按返回目标展开全船工作台，事项大全保留原筛选上下文。
2. **观察页助手内容源**：原来档案分支优先于效果观察分支，助手会显示旧检查资料或过时执行卡。现在按当前观察源回答，展示实际措施、现场验收、每日效果；每个动作对应一问一答。
3. **观察页输入分流**：原来观察中的提问也被送往旧档案问答。现在反复／资料不足反馈接续原事件；重开后按观察轮次隔离对话，闭环后查询保留本轮结束事实。
4. **闭环后的表述**：观察曲线下方已结束后仍提示“待确认闭环”。现改为已闭环及人工确认已留档，与页头和助手保持一致。
5. **材料名称**：将操作说明里的预警事项名称校准为实际页面名称“主机润滑供油异常预警”。
