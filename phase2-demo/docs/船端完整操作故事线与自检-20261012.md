# 船端操作故事线与本轮自检 · 2026-10-12

适用：船端 ship-maintenance 仓库，phase2-demo-20261009 分支，基于 23f0093 的本地调整。预览：http://127.0.0.1:8785/#/situation 。本材料描述本轮可操作的原型故事；一期数据用于案例参考，新增现场反馈为体验用情节，不作为真实设备操作依据。

## 一、轮机长先看什么

轮机长进入“态势”，先看完整船舶孪生图。上方图中设备卡常驻，状态以信号灯呈现，卡内列出具体关注或待办名称。设备名称和卡片空白区域进入设备概览，事项名称进入原事项，待办名称进入原待办。全船层不显示伴随助手，避免一进来把注意力引向聊天。

孪生图下方是 AI 全船运行概况，与图上下分区，不盖住设备或热区。内容由一段 Markdown 渲染，依次为当前结论、综合依据、下一步建议。它先指出主机冷却能力需要优先核实，再解释温升与流量下降的关联，以及单缸排温、轴承振动、辅机油压、舵机油温为何需要分别核实，最后建议查看主机运行情况。全船这一层不直接要求轮机长拆检或维修。

点击图上的主机浮动卡，进入设备层；概况区不再重复设置下钻按钮。正常或暂时无事项的设备也有概况、证据范围和下一步建议，不以空页面代替概览。

## 二、主机概览：从综合判断到具体关注

主机概览左侧是设备健康研判，依次呈现综合判断、分析依据、安排建议；详细分析按需展开。综合判断解释冷却回路异常、单缸排温偏离和轴承振动缓升的关系与差异，不把它们简单列成几条告警，也不把不同部位变化强行合成一个故障。

主内容右侧“值得关注”只保留轮机长需要判断的建议：3号缸排温偏离扩大、连杆轴承提前检查。已建立待办的事项从这里退出，转到“当前待办”，不要求重复决定。当前待办隐藏已处理任务；已处理记录从设备动态回查。这里的“右侧值得关注”是设备概览的内容分区，与更右侧检修助手区分。

轮机长点击“3#缸 · 排温偏离扩大”，进入关注详情，查看最新判断；在“变化证据”中了解相近工况下排温及缸间差值的变化、比较条件和现场证据缺口；“跟踪记录”保留此前变化与决定。助手由本次查看动作带出问题与回答，解释为什么值得核实，而不是突然推送另一条与当前操作无关的任务。

当前数据支持安排现场检查，尚不能认定喷油器或排气阀故障。轮机长点击“接受建议，安排待办”，在展开表单中选择负责人，例如赵明（三管轮）。任务范围默认带入现场排温、工况、异响和测量连接的核实要求；协作人员、计划时间等可选安排按需展开。阶段内不再重复选择负责人。

另一种决定是“忽略本次建议”：填写本次不安排的依据，记录决定而不创建待办。忽略建议不等于证明设备正常；后续可以重新安排，并保留原决定。

## 三、进入待办中心，先看全量研判

确认建立后进入待办首页，先阅读上方 AI 待办研判。研判仍为一个 Markdown 内容区，通过标题、分段和加粗表达层次，不拆成固定列或一排同规格卡片。

- 当前结论：当前几项任务推进中，优先了解哪项任务的进展。
- 原因与进展：例如冷却系统温升与流量下降相互印证；哪些任务仍缺现场反馈，哪些已经进入实际作业。
- 下一步建议：查看优先任务的当前阶段和最新反馈，了解当班核实条件，沿已有任务推进，不重复派单；不从总览直接跳到未经确认的维修。

本轮初始有主机冷却水异常、2号辅机油压偏低、舵机油温超限三项已建立任务。3号缸任务建立后共四项；轴承提前检查建议仍待人员决定，不混入已建立任务数量。列表卡显示任务标题、当前阶段摘要、设备及负责人。

点击“主机3#缸排温偏离检查”卡片，进入原有详情。顶部仍是原阶段卡；左侧是当前阶段产物与操作，右侧助手解释当前依据、接收补充并保留回执。只解锁已经到达的阶段，回看历史不自动推进。

## 四、主故事：3号缸核实后确立异常，再排查与维修

### 1. 任务概览与检查准备

先看概况/结论、判断依据、下一步建议。当前仅要求核实排温真实性与异响是否可复现。点击“进入现场检查”，阅读检查准备，点击“已了解，开始检查”。

第一步“核对现场排温读数”：本故事选择“现场与系统一致”，备注可写“450 rpm、负荷70%，现场排温432℃，与采集一致”。点击下一步。

第二步“观察3#缸异响与振动”：本故事选择“异响可复现”，备注记录相近稳定负荷下的发生位置及现象，然后提交本轮反馈。右侧保留逐项结果、备注、反馈人和时间；负责人来自发起待办时的安排，没有新增阶段指派表。

如果选择未见异常、读数不一致或无法确认，也能保存实际反馈，但不强行确立本故事中的异常，更不能为迎合流程把它改成发现故障。

### 2. 异常确立与事件概览

现场一致读数与可复现异响共同支持需要响应，标题由“排温偏离检查”接续为“排温异常”，仍是同一待办。此前关注与检查证据保留，不复制另一张事件。

事件概览先看结论、依据及下一步，再查看“数据观测”和“候选原因”。数据页展示原异常指标与趋势。候选原因区分喷油器雾化、排气阀密封与测量链路，解释为什么优先排查以及什么现场证据可以区分。

### 3. 排查准备与逐项反馈

进入排查，先阅读准备及安全条件，再按步骤记录实际发现。本故事第一项“校验3#缸喷油器雾化”选择发现异常，备注“喷孔积炭，喷雾形态异常”；第二项“检查排气阀密封”选择未见异常，记录检查结果。提交后才进入喷油器维修。

如果两项均异常、均未见异常或无法确认，反馈保留，继续核实；当前原型不自动生成未实现的另一套诊断方案，也不强行进入预设喷油器维修。普通助手追问不替代结构化结果确认。

### 4. 维修与验收

维修页保留维修准备、备件清单、维修步骤、验收确认。阅读准备及备件后，按两项步骤记录拆检处理与复装校验的实际完成情况、备注、附件。

验收确认先展示验收要求及核对方法，再填写共用执行记录：实际部位、措施、已发生的执行时间、验收复测、执行状态、原异常验收结果和可比数据。左右两侧共用同一草稿，从一侧确认后不会重复提交。

本故事可填写清洁并校验喷油器、复装密封无泄漏、相近工况排温差回落到3℃且未再出现原异响；各值为本故事的模拟现场反馈。选择“执行及验收已完成”和“原异常已解决，验收通过”，确认实际可比数据后提交。本轮人工处理记为已处理，后续持续效果在设备态势接续，而非仅凭完成表单宣称整个事件闭环。

必须可体验的不同结果：

- 作业未完成：选择保留进展；继续当前维修，不虚构已验收。
- 尚未验收：不能以已完成方式推进；保留进展后补充。
- 作业完成但原异常仍存在：选择“原异常仍存在，继续排查”；回到同一事件的检查/排查阶段，上轮执行、验收与现场反馈保留，新一轮草稿清空旧完成值，不重复建单。
- 验收通过但缺少可比监测：保存处理记录，说明效果待补；不生成改善或稳定结论。
- 验收通过且有可比数据：接续效果观察；修后反复仍返回原事件，数据不足延长并补齐，稳定后结束本轮观察。人工处理完成、观察结束、事件关闭分别理解。

## 五、补充案例：沿一期材料扩展，不另造页面

### 2号辅机油压偏低

入口：待办中心卡片；也可从全船孪生图的2号辅机卡进入概览，再看当前待办。

一期原始材料为 EVT-2026-002，快照包括机油压力0.18 MPa、滤器压差0.08 MPa、油温68.5℃、液位82%、泵出口压力0.35 MPa。先看压力下降与压差升高的关联，再核实滤器和供油/管路。不能凭泵出口单次压力正常排除其他问题。

故事的支持分支是现场确认滤器异常、泵与管路检查未见异常，才进入滤芯处理；维修后核对油压、压差、工况及密封。未解决回到原事件，不以清洗已经完成代替油压恢复。其他检查结果保存继续研判。

### 舵机液压油温度超限

入口：待办中心卡片；全船舵机卡可直接打开原待办，也可先进入设备概览。

一期原始材料为 EVT-2026-003，快照包括油温78℃、原材料参考上限65℃、油压12.5 MPa、油位68%、流量45.2 L/min、冷却水温38.5℃。先看油温异常与散热/负荷两个方向，现场核对冷却通路、操舵工况与油液状态。

故事的支持分支是冷却通路发现异常、负荷及油液检查未见异常，才进入对应冷却器处理；复测应在可比操舵条件下核对油温和响应，不能用静置降温充当修复效果。仍异常与证据不足沿同一标准处理。

以上快照来自一期；后续处理步骤及反馈分支是本轮补充的原型体验情节，不是一期已经发生的真实维修记录，也不是设备通用阈值。
