## 1. 案例目标

以轮机长审阅维保建议为主体，展示建议来自多次设备健康分析、同一问题的持续跟踪，以及先前派工取得并确认的现场证据。

候选标题：**主机3号缸喷油器提前清洁与校验建议**。

建议对象为喷油器，关注对象起初是3号缸排温变化。监测偏差不直接证明喷油器衰减；只有后续现场证据支持具体部件维护，才提出本建议。建议先清洁与复校，不直接决定更换。

本案例不使用振动数据、轴承温度或靠港窗口，不假设本部件已有周期小时、剩余寿命、船管工单或安排。

## 4. 前置现场取证：模拟记录内容

以下均为可审阅的演示故事材料，需按人员确认流程留存，不作为真实船舶检查事实：

1. **读数与工况核实**：现场记录与相应系统片段方向一致；排除把明显不同工况混成一条趋势。核实时间及工况应有记录，不凭一句“读数正常”完成。
2. **测温链路核对**：提供本次已核查范围与结果，不用“未见明显异常”证明全部采集链路无问题。
3. **部件观察／检查证据**：已有按设备规程取得的喷嘴积炭观察记录，以及喷油器状态检查或校验报告；模拟报告显示喷雾状态未达到该报告所引用的设备要求。不补造校验压力、尺寸或厂家限值。
4. **结果确认**：人员确认报告属于本机3号缸喷油器，明确本次观察／检查的对象、时间、方法和范围。其他候选原因的证据不足如实保留，不写成已全部排除。

只有读数核实、异响描述或机外观察时，不足以直接落到喷油器维护，本案例必须保留第3项真正支持该部件建议的材料。若演示只完成前两项，应停留在“继续取证”，不能进入D阶段。

前置取证不是维护已执行。即使此前有状态校验，本次建议仍是清洁后复校；不把校验不良写成已经更换或保养完成。

## 5. 轮机长详情的拟定内容

### 建议概览

**建议摘要**：建议安排3号缸喷油器清洁与复校。持续跟踪中的排温偏差与已确认的喷嘴积炭及状态检查记录共同支持本次维护建议；不直接批准换件。

**当前依据**：排温变化的有效比较记录、现场读数核实、喷嘴观察材料、部件检查／校验报告及确认人。每项保留来源及时间；没有依据的不显示虚构指标。

**判断范围**：现有材料支持该部件需要维护评估，不代表所有排温变化均由该部件造成；清洁和复校后的实际效果仍需验证。

**为什么现在考虑安排**：已经取得指向该部件的现场证据，不再只是等待确认排温变化是否真实。原计划如未取得，说明无法给出精确提前小时数；建议的必要性来自状态证据，不来自不存在的靠港窗口。

**轮机长当前任务**：审阅清洁／复校措施是否合理，决定是否接续原事件安排维护。执行时间、人员、停机隔离及备件条件由人员安排，不自动生成。

### 依据与评估

- 来源过程：建立关注 → 后续变化 → 派工取证 → 现场结果确认 → 提出本建议。
- 事实／判断／限制对照：
  - 事实：已有演示可比排温变化及已确认的模拟现场记录。
  - 判断：综合证据支持针对喷油器提出清洁与复校建议。
  - 限制：仍需对措施和后续效果进行评估，不直接判定必须换件，不给出寿命预测。
- 已有取证清单：逐项展示确认人、时间及来源，不能把已取得材料又写成“尚缺现场证据”。
- 执行条件清单：人员、实施时间、停机隔离、相关许可及所需资源；与建议证据分开，不使用靠港倒计时。
- 原计划／正式工单：真实接入或明确的接口演示返回若无对应记录，显示未取得；不能用原轴承工单冒充本喷油器安排。

### 决定与进展

- 轮机长审阅决定及理由。
- 原问题事件的安排和负责人；源关注、源事件及建议互相可回查。
- 实际清洁／复校记录、执行时间、验收及来源；此前取证记录不当作本次维护记录。
- 处理后排温相对偏差的可比观察；没有实际数据时不默认恢复正常。
