# 智能机舱信息地图说明

核对基线：`98ce7fc`（2026-11-02）。两张地图只表达该版本已实现的页面操作、信息归属与状态变化。

## 四类事件与三种结束

报警、预警、异动跟踪、效果观察是同级事件类型。效果观察有独立编号、工作区、阶段记录、采样、会话、后续任务和决策入口。

| 结果 | 发生条件 | 后续与记录 |
|---|---|---|
| 本轮任务完成 | 按批准范围完整执行并成功提交报告 | 不等轮机长下一次决定；实际受阻仍记未完成；不代表设备恢复 |
| 原事件结束当前处置 | 决策确认转入效果观察 | 原事件状态／阶段为“已转效果观察”，退出首页“处置中”；保留任务、报告和观察事件入口；尚无闭环时间及闭环报告 |
| 事件闭环归档 | 轮机长说明依据并确认闭环 | 状态为“已闭环”，阶段为“闭环归档”；保留关闭依据、报告及历轮历史 |
| 关联链路闭环 | 任一效果观察事件人工闭环 | 沿显式关联关系联动来源事件、同链其他观察及后续关联事件；无关联事件不受影响 |

关联链路闭环会停止相关采样。尚在执行、等待或生成报告的关联任务按“终止”留存，取消进行中的报告生成并保留原填写记录，不改写成已完成。已经归档的事件保留原闭环历史。

## 独立效果观察的操作路径

1. 排查、维修或维保任务已有提交报告，当前没有优先处理的执行中、等待或实际受阻状态。
2. 轮机长审阅AI分析，在决策弹窗选择“效果观察”，填写依据并确认。
3. 来源事件结束当前处置；建立独立观察事件，顶部保留来源事件、来源任务和来源报告快照的跳转入口。重复确认同一来源报告复用已建观察事件。
4. 观察页面保留曲线、实时读数、工况条件、窗口记录、AI建议、阶段报告及决策弹窗；后续任务可通过阶段条回查。
5. 来源报警／预警按两小时窗口、至少30分钟可比工况判断；来源异动按一周窗口、至少6小时可比工况判断。核对稳态航行、转速、负荷、覆盖与原异常，时间到期不自动闭环。
6. 等待窗口时没有新增人员执行任务；到期形成“待观察确认”和轮机长决策待办。缺测或工况不适用时保留证据缺口。
7. 可在本观察事件派发复查；核实后观察可按条件派发维修，修后需再次处理先复查。后续任务与报告归属当前观察事件，不重新打开已转出的来源事件。
8. 再次选择“效果观察”沿用本观察事件，延续采样及下一周期；人工闭环则联动整个显式关联链路归档。

历史事件内的旧观察数据会迁移为独立事件，沿用原开始时间和观察记录。地图不创建业务事件或修改浏览器中的业务数据。

## 状态与阶段

| 业务状态 | 页面含义 |
|---|---|
| 待决策 | 初始风险提醒，或排查回交／复查发现异常后等待轮机长；不再使用“待处置决策” |
| 排查中／复查中／维修中／维保执行中 | 已确认派发本轮独立任务 |
| 待结果处置 | 维修／维保报告回交，或复查无异常后等待后续安排 |
| 已转效果观察 | 原事件结束处置，后续进入关联观察事件；尚未闭环归档 |
| 效果观察中／待观察确认 | 观察窗口进行中／到期等待人工判断 |
| 等待执行条件／待后续决策 | 原任务等待恢复或终止／终止后仍需安排事件后续 |
| 已闭环 | 人工关闭或由关联观察闭环联动归档 |

“决策中”是当前记录的阶段名称，“待决策”是业务状态；两者分别表达当前所处环节与等待动作。阶段条中的历轮排查、维修、决定及提交记录继续保留。

## 页面入口与任务报告

| 入口 | 去向 |
|---|---|
| 首页“值得关注” | 事件、本人任务或报告；效果观察类型浅绿色，已转出的原事件退出“处置中” |
| 事件中心 | 四类事件当前工作区；转出或闭环的记录仍可回查 |
| 决策／确认待办 | 当前事件AI分析或观察工作区，通过弹窗决策 |
| 执行待办／我派发的 | 独立任务详情 `/#/tasks/:taskId`，保留所属事件入口 |
| 独立观察顶部关联 | 返回来源事件、来源任务或来源报告 |
| 原事件已转效果观察阶段 | 进入关联的独立效果观察事件 |

任务助手默认收起，入口在任务页右上角；执行表在主区域逐步填写，备注支持语音输入与AI总结。AI排查／维修建议用部件标签概括重点、子步骤编号说明操作。AI分析页保留决策要点，决策弹窗可进入相应AI建议页。

原始执行记录先保存，AI流式整理报告，完整结构校验后写入并交轮机长。生成失败保留原记录并支持重试。恢复原任务后的再次提交生成独立报告快照；报告补充修订保留旧版本，不增加提交次数。未闭环事件的执行人可以补充本人报告，闭环后仅回查。

实际受阻优先走剩余作业、等待、恢复、终止或说明剩余事项后闭环。等待期间保留原任务编号、步骤和执行人；恢复须填写依据和新的完成时限。“不适用”不进入补做清单，原因未明不直接等于执行受阻。

同步岸基只在已有报告时开放：打开最近报告，核对或编辑同步副本，确认后保存待接收快照、toast及会话记录。它不改变当前事件阶段，不表示岸基已经接收。

## 两张地图的结构

- `事件分支流转图.html`：报警、预警、异动跟踪、独立效果观察、任务受阻、贯穿全程与完整总图。观察分支内的复查、维修及受阻返回都定位当前观察事件；浅绿色“处置结束”节点与“闭环归档”节点分开。
- `智能机舱-态势与事项信息地图.html`：信息总览、三类来源事件、独立效果观察、状态与归属、用户动线，共7个视图。保留来源／加工／场景／事件／任务／结果6层归属；观察事件属于事件层，转出与链路归档分别展示。
- 四个历史来源案例保留原始测量、来源、统计、冲突与限制；只更新流程呈现，不伪造已发生的观察案例。

## 数据与实现边界

当前自动采样和工况使用内置数据源；任务、报告、决定与提醒保存在同源浏览器。角色切换不是正式账号权限系统。正式船管工单写入、真实报警合并、闭环后再发关联判断、岸基接收回执均不画成已接通流程。

核对来源：`eventLifecycle.js`、`observationEvents.js`、`lifecycleDecisions.js`、`lifecycleObservation.js`、`taskExecution.js`、`observationContext.js`、`observationConditions.js`、`EventLifecycleView.vue`。地图节点附具体源码位置。
