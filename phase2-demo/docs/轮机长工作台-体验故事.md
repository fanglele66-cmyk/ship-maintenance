# 船端：轮机长决策与负责人执行

进入应用先到态势中心。左侧竖版孪生图只呈现设备名称和信号灯，点击进入设备概览；右上分析全船风险及主机优先的依据，右下先展示待决策事项，每次4条，超过可查看更多。已派发事项单独切换查看。

事项先按设备当前最高风险确定设备顺序，再按报警事件、预警事件、异动跟踪、维保建议排序。报警与多指标预警优先核实；单项异动先判断是否需要检查；维保建议先判断是否确有必要提前，不直接换件。

初始场景：主机冷却水报警、主机润滑供油预警、3号缸异动、连杆轴承提前维保建议，以及空压机加载时间异动均等待轮机长决定。舵机报警已派发给赵明，用来对照已派发状态。

点击主机冷却水报警，查看判断、证据和建议。轮机长可接受建议并选择负责人，确认后形成唯一处理任务；怀疑误报时提交现场依据，原报警继续保留，直到核对后作出决定。

选择润滑供油预警，先核对油压和滤器压差与现场是否一致，再排查异常部位。选择异动跟踪时，先确认是否安排检查；选择维保建议时，先评估提前必要性与靠港、安全、备件条件。采纳时选择负责人；不采纳记录依据，不改变原周期计划。

派发后，事项进入已派发列表及待办中心。待办中心可按负责人查看，AI建议只针对已派发任务。进入任务后沿既有概览、检查/排查、维修执行、验收及效果观察流程推进，负责人在任务级留痕，不增加阶段内反复指派。

设备下钻保留：设备概览、传感器数据、设备动态、待办处理、异动跟踪、维保建议。设备概览只保留研判；具体事项与历史记录通过各自页签查看。
