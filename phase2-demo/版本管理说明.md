# 源码与版本管理

当前源码已由 Git 管理，并同步到本项目的 Sites 源码仓库。公网仍使用同一站点地址。

## 后续工作方式

- 日常调整以 Git 提交保存；每次发布记录修改内容与对应提交。
- 公网发布保留平台版本记录，可追溯到发布时的源码。
- 默认不再为每次小改动另做源码压缩包。需要给同事离线部署或正式交付时，从指定提交生成一个源码包。
- 依赖目录、构建产物、日志、发布归档及源码压缩包均不纳入 Git；本机工具配置与发布凭据不进入源码。
- 既有交付包保留原状；引入版本记录本身不会清理已经生成的文件。
