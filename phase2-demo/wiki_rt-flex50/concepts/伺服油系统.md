# 伺服油系统

## 定义

伺服油系统（Servo oil system）是RT-flex发动机共轨液压系统的一部分，为气门控制单元VCU和喷射控制单元ICU提供高压伺服油，驱动排气阀和燃油喷射的执行机构。

## 详细说明

### 系统组成

| 组件 | 说明 |
|------|------|
| [[伺服油轨]] | 存储80-190 bar高压伺服油（随负载变化） |
| [[RT-flex伺服油泵]] | Dynex品牌伺服油泵，带补偿阀和电磁阀 |
| [[伺服油过滤系统]] | 6μm主滤+36μm旁通滤，自动反冲洗 |
| [[气门控制单元VCU]] | 使用伺服油驱动排气阀 |
| [[喷射控制单元ICU]] | 使用伺服油控制燃油喷射 |

### 压力特性

- **低压状态**：80 bar
- **高压状态**：190 bar
- **压力调节**：随负载自动调节（PWM控制）
- **控制方式**：不同FCM控制不同泵

### 功能

1. **排气阀驱动**：为VCU提供高压伺服油，驱动排气阀开启和关闭
2. **喷油控制**：为ICU提供控制油，实现燃油喷射的精确控制
3. **系统过滤**：自动过滤保持伺服油清洁度（6μm）

## 与其他系统的关系

- 伺服油轨压力由WECS-9520通过燃油量限制器监控
- 伺服油泵由FCM-20模块通过PWM控制
- 伺服油过滤系统使用控制空气进行自动反冲洗
