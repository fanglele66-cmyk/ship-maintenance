# 缩写术语表

## 通用缩写

| 缩写 | 全称 | 说明 |
|------|------|------|
| AHD | Ahead | 正车（前进） |
| ALM | Alarm | 报警 |
| AST | Astern | 倒车（后退） |
| BDC | Bottom Dead Center | 下止点 |
| BFO | Bunker Fuel Oil | 船用燃料油 |
| BN | Base Number | 碱值 |
| CCAI | Calculated Carbon Aromaticity Index | 计算碳芳香度指数 |
| CMCR | Contract Maximum Continuous Rating | 合同最大持续功率 |
| COC | Cleveland Open Cup | 克利夫兰开杯法（闪点测定） |
| HFO | Heavy Fuel Oil | 重燃油 |
| IMO | International Maritime Organisation | 国际海事组织 |
| ISO | International Standard Organisation | 国际标准化组织 |
| JIS | Japanese Industrial Standards | 日本工业标准 |
| MCR | Maximum Continuous Rating | 最大持续功率 |
| MCR | Micro Carbon Residue | 微量碳残渣（与最大持续功率为同一缩写，需根据上下文区分） |
| MDO | Marine Diesel Oil | 船用柴油 |
| mep | mean effective pressure | 平均有效压力 |
| MGO | Marine Gas Oil | 船用轻柴油 |
| PMCC | Pensky Martens Closed Cup method | 宾斯基-马丁闭杯法（闪点测定） |
| RCS | Remote Control System | 遥控系统 |
| SCR | Selective Catalytic Reduction | 选择性催化还原 |
| SIPWA-TP | Sulzer Integrated Piston ring Wear detecting Arrangement with Trend Processing | Sulzer综合活塞环磨损检测装置及趋势处理 |
| SHD | SHut Down | 停机（紧急停机） |
| SHF | Sediment by Hot Filtration | 热过滤沉淀物 |
| SLD | SLow Down | 减速（降速运行） |
| TDC | Top Dead Center | 上止点 |

> 注意：相同缩写（如 MCR）可根据上下文区分不同含义。
