# 主机偶发超速报警停车故障案例

## 概述

这是一起长航琥珀轮flex50主机2012年7月偶发超速报警停车的故障案例。主机在正常运行和倒车试验时两次出现OVERSPEED报警导致SAFETY SHUTDOWN。经KONGSBERG服务商指导，清洁检查测速探头及齿轮面、调整探头间隙后，故障得以解决。

## 基本信息

| 项目 | 内容 |
|------|------|
| **船舶** | 长航琥珀轮 |
| **主机机型** | RT-flex50 |
| **故障时间** | 2012年7月1日、7月3日 |
| **报警信息** | OVERSPEED SYS.1-SW BACK, OVERSPEED FROM RPM UNIT |
| **服务商** | KONGSBERG MARITIME CHINA (SHANGHAI) LTD |

## 故障经过

### 第一次故障（2012年7月1日）

| 时间 | 事件 |
|------|------|
| 2012-07-01 15:44 | 主机正常运行中，监控系统警报OVERSPEED SYS.1-SW BACK, OVERSPEED FROM RPM UNIT |
| 随即 | 主机SAFETY SHUTDOWN |
| 立即 | 通知驾驶台把车钟手柄拉到STOP位置，空气阀打开 |
| 再次启动 | 主机可以正常运行，无其他异常现象 |

**检查项目**：

| 检查项 | 检查结果 |
|--------|---------|
| 测速探头 | 接线正常，无松动，指示灯正常亮，传感器表面干净无垢 |
| 测速控制单元E20 | 内部接线无松动，各指示灯状态正常 |
| E10控制箱 | ESU、MEI两单元正常，各接线无松动，E20至E10的OVERSPEED RELAY数字量信号接线正常 |

### 第二次故障（2012年7月3日）

| 时间 | 事件 |
|------|------|
| 2012-07-03 17:12 | 主机停车后，进行倒车试验 |
| 试验中 | 再次出现主机警报OVERSPEED FROM RPM UNIT |
| 随即 | 主机SAFETY SHUTDOWN |
| 处理 | 重复之前做法，主机又正常运行，正车/倒车/加速等功能均正常 |

**初步分析**：可能是测速单元E20的两个单元故障所致，但几经检查始终没有找到故障原因。

## KONGSBERG服务商意见

服务商：Wei Guochuan（资深主机遥控服务商）

### 诊断分析

| 分析要点 | 说明 |
|---------|------|
| 报警判断 | 如果历史记录中只有OVERSPEED SYS.1-SW报警，则说明是第一组传感器引起的overspeed，即pickup1.1、pickup1.2 |
| 观察建议 | 主机正常运行时观察ACP上mimic图中各个传感器的转速值，是否有传感器显示与其它不同的转速 |
| 信号问题 | 如果有些转速显示不正常或经常会跳变，则此传感器信号有问题 |
| 线路检查 | 船员已对有关传感器的相关接线进行了详细的检查，线路上应该不存在问题 |

### 建议措施

| 序号 | 措施 |
|------|------|
| 1 | 使用系统中的short trend功能，将各个转速值的tag设入其中，查看发生overspeed时各个转速的显示值 |
| 2 | 如果发现某个传感器的显示值有问题，可以先尝试更换一个传感器（如果船上有备件） |
| 3 | 检查传感器间隙，应为4mm左右 |
| 4 | 飞轮的齿也须清洁 |

## 处理措施与结果

### 船舶执行的工作

| 项目 | 内容 |
|------|------|
| 清洁检查 | 对主机测速探头及主机盘车齿轮面进行清洁检查 |
| 间隙调整 | 测速探头与齿轮面间隙调整为3.5mm |
| 监测设置 | 监视器上设定好了速度监测曲线 |

### 最终结果

调整间隙后，未再发生超速报警。

## 关键知识点

- **OVERSPEED报警分级**：SYS.1-SW报警指向第一组传感器（pickup1.1、pickup1.2）
- **测速探头间隙**：标准应为4mm左右，本例调整为3.5mm
- **故障诊断方法**：
  - 观察ACP上mimic图各传感器转速值
  - 使用short trend功能查看历史数据
  - 检查传感器间隙和飞轮齿清洁度
- **间歇性故障**：偶发报警需关注传感器信号跳变、间隙变化等因素
- **服务商支持**：KONGSBERG等原厂服务商提供专业诊断建议
